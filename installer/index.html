FOSSA ⚡ WEB INSTALLER

Flash the firmware and configure your FOSSA ATM (ESP32, WT32-SC01 display) from the browser. Use Google Chrome or Microsoft Edge on a desktop computer.

1 – Flash firmware

  • Connect the FOSSA to your computer via USB.
  • Leave the latest firmware version selected.
  • Press Flash and follow the instructions. Choose Erase device for a fresh install.
Your browser does not support installing on ESP devices. Use Google Chrome or Microsoft Edge. Not allowed on HTTP – open this page via HTTPS.

Without Erase device the stored configuration is kept when you update the firmware.

2 – Connect

  • Close other programs that use the USB port (serial monitor, flash dialog).
  • Press Connect and select the serial port of your FOSSA.
  • The page puts the device into config mode automatically. A device without stored settings (fresh install) starts in config mode by itself and shows USB config mode.
  • If config mode does not start, press Restart device. As a fallback, tap the screen within 6 seconds after power-up.
❌ Not connected ❌ No config mode

3 – Configure

All values are pre-filled with defaults. Only the ATM string is required. Read config loads the values currently stored on the device.
